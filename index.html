1. Variablen

Kurz erklärt

Eine Variable speichert einen Wert unter einem bestimmten Namen. Der Wert kann im Laufe des Programms verändert werden.

preis = 20
menge = 3

gesamtpreis = preis * menge

Mit dem Gleichheitszeichen = wird einer Variable ein Wert zugewiesen. Bei einer erneuten Zuweisung wird der bisherige Wert überschrieben.

2. Ausgabe mit print()

Kurz erklärt

Mit print() werden Texte, Variablen und Berechnungsergebnisse ausgegeben. Texte stehen in Anführungszeichen.

name = "Alex"
alter = 17

print("Hallo Welt!")
print(name)
print("Alter:", alter)
print(f"{name} ist {alter} Jahre alt.")

Der letzte Befehl verwendet einen f-String. Die Variablen innerhalb der geschweiften Klammern werden durch ihre Werte ersetzt.

3. Datentypen und Casting

Kurz erklärt

Python unterscheidet verschiedene Datentypen.

DatentypBedeutungBeispiel
strText (String)"Hallo"
intGanze Zahl (Integer)42
floatKommazahl (Float)3.14
boolWahrheitswert (Boolean)True

Mit Casting wird ein Wert in einen anderen Datentyp umgewandelt.

zahl = "25"
zahl = int(zahl)
print(zahl + 5)

Aus dem Text "25" wird die ganze Zahl 25. Nun kann mit ihr gerechnet werden. Wichtige Umwandlungen sind int(), float() und str().

4. Eingaben mit input()

Kurz erklärt

Mit input() kann ein Programm Informationen vom Benutzer entgegennehmen.

name = input("Wie heißt du? ")
print(f"Hallo {name}!")

Wichtig: input() liefert immer einen String zurück. Soll mit einer eingegebenen Zahl gerechnet werden, muss diese zunächst umgewandelt werden.

alter = int(input("Wie alt bist du? "))
print(f"In fünf Jahren bist du {alter + 5} Jahre alt.")

5. Struktogramme

Kurz erklärt

Struktogramme (Nassi-Shneiderman-Diagramme) stellen den Ablauf eines Programms grafisch dar. Sie helfen dabei, einen Algorithmus zu planen, bevor er in Python umgesetzt wird.

Drei wichtige Grundelemente sind:

  • Sequenz: Anweisungen werden nacheinander ausgeführt.
  • Auswahl: Abhängig von einer Bedingung werden unterschiedliche Anweisungen ausgeführt.
  • Wiederholung: Anweisungen werden mehrfach ausgeführt.

Eine Sequenz könnte beispielsweise so aussehen:

Preis eingeben
Menge eingeben
Gesamtpreis = Preis × Menge
Gesamtpreis ausgeben

Für die folgenden Übungen verwenden wir den Editor Struktog der TU Dresden.

6. Bedingte Verzweigungen

Kurz erklärt

Mit if, elif und else entscheidet ein Programm, welche Anweisungen ausgeführt werden.

punkte = 75

if punkte >= 90:
    print("Sehr gut")
elif punkte >= 50:
    print("Bestanden")
else:
    print("Nicht bestanden")

Python prüft die Bedingungen nacheinander. Sobald eine Bedingung zutrifft, wird der zugehörige Block ausgeführt. Die übrigen Zweige werden übersprungen.

Wichtige Vergleichsoperatoren:

OperatorBedeutung
==gleich
!=ungleich
< / >kleiner / größer
<= / >=kleiner oder gleich / größer oder gleich

Mehrere Bedingungen lassen sich mit and, or und not verknüpfen.

7. Listen

Kurz erklärt

Eine Liste speichert mehrere Werte unter einem gemeinsamen Variablennamen.

namen = ["Anna", "Ben", "Chris"]

Die Elemente werden über ihren Index angesprochen. Der erste Index ist immer 0.

print(namen[0])      # Anna

namen[1] = "Lisa"    # Element ersetzen
namen.append("Tom")  # Element anhängen
namen.remove("Anna") # Wert entfernen

Weitere wichtige Befehle sind insert() zum Einfügen, pop() zum Entfernen über einen Index und clear() zum vollständigen Leeren.

Mit einem negativen Index kann vom Ende der Liste zugegriffen werden:

print(namen[-1])    # letztes Element

8. Zeichnen mit Turtle

Kurz erklärt

Mit dem Python-Modul turtle können grafische Figuren gezeichnet werden. Eine Turtle bewegt sich über die Zeichenfläche. Solange ihr Stift abgesenkt ist, hinterlässt sie eine Linie.

import turtle

t = turtle.Turtle()

t.forward(100)
t.right(90)
t.forward(100)

turtle.done()

Einige wichtige Befehle:

BefehlBedeutung
t.forward(100)100 Pixel vorwärts
t.backward(50)50 Pixel rückwärts
t.right(90)90° nach rechts
t.left(90)90° nach links
t.penup()Stift anheben
t.pendown()Stift absenken
t.pencolor("red")Linienfarbe ändern
t.fillcolor("blue")Füllfarbe festlegen
t.begin_fill()Füllung beginnen
t.end_fill()Füllung abschließen
t.circle(50)Kreis mit Radius 50 zeichnen
